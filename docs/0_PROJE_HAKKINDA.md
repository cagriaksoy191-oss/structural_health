# 🏗️ V12 Cobalt - Yapısal Sağlık İzleme ve Risk Analiz Platformu

## 🚀 Proje Hakkında
Bu proje, binaların deprem riskini analiz eden hibrit bir yapay zeka sistemidir.
Fuzzy Logic (Bulanık Mantık), Random Forest ve LLM (Qwen3) teknolojilerini birleştirerek detaylı bina sağlık raporları üretir.
